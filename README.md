# Mac Studio M3 Ultra 活用計画（Sovereign Node & Private Workstation）

Mac Studio（M3 Ultra / 32C CPU / 80C GPU / 512GB Unified Memory / 8TB SSD）1台を、
**自己主権型の暗号資産検証インフラ ＋ 秘匿性の高い個人作業環境** として設計・構築する計画。

本リポジトリは「計画」を最重視する。実装より先に、要件・制約・設計判断を文書として積み上げる。

## 文書構成

| ファイル | 内容 |
|---|---|
| `docs/01-requirements.md` | 前提・制約・要件（確定分と未確定分） |
| `docs/02-decision-log.md` | 設計判断の記録（ADR形式） |

## 取り扱い注意

このリポジトリは公開設定である。資産額・個人属性・ネットワーク構成の実値・鍵に関する情報は
**一切記載しない**。設計書は「誰が読んでも攻撃の手がかりにならない」粒度で書く。
