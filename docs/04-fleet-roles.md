# 04. 複数台の役割設計（検討用たたき台）

最終更新: 2026-09-06（ラウンド5・決定前）

4 台の同一構成 Mac Studio をどう割り当てるか。以下は候補となる「役割」と、
それを組み合わせた構成案。利用者の回答を受けて 1 案に確定する。

## 1. 候補となる役割

| 記号 | 役割 | 概要 | ネット接続 | 攻撃面 |
|---|---|---|---|---|
| N | **Bitcoin ノード筐体** | Bitcoin Core（onion-only）＋ Fulcrum ＋ 軽量ダッシュボード。それ以外を入れない | Tor のみ | 最小 |
| L | **LLM 筐体** | LM Studio ＋ Open WebUI（RAG）。onion で公開 | Tor のみ（モデル取得は要判断） | 中 |
| L2 | **LLM 拡張筐体** | L と Thunderbolt 5 で直結し、分散推論で超大型モデルを動かす | 外部接続なし（L 経由のみ） | 小 |
| S | **オフライン署名筐体** | 一度も（初期設定の認証以外）ネットに繋がない。Electrum で PSBT に署名。QR/USB で受け渡し | **なし**（Wi-Fi/BT を無効化） | 物理のみ |
| B | **予備・バックアップ筐体** | N の完全な複製を保持し、N 故障時に即座に切り替える。または開封せず保管 | Tor のみ、または未接続 | 小 |
| D | **開発・検証筐体** | 新しい設定やソフトを本番（N/L）に入れる前に試す。壊してよい | Tor のみ | 中 |

### 役割 S（オフライン署名）についての注意

- Apple Silicon Mac は初回セットアップ時に Apple の認証サーバーへの接続が必須。
  その 1 回だけ接続し、以後は Wi-Fi・Bluetooth を無効化して物理的にケーブルも挿さない
- Wi-Fi/Bluetooth の無線モジュールは取り外せないため、「完全なエアギャップ」ではなく
  「ソフトウェア的に無効化した準エアギャップ」になる。Tails を USB 起動する x86 PC の方が
  エアギャップとしては純度が高い。ただし S を使えば **Tails を「オンライン専用」に単純化**できる
- 予算ゼロの範囲で署名環境を専用化できるのが最大の利点（ADR-006 の代替案）

## 2. 構成案

### 案 A: 守り重視（N / L / S / B）

```
[N] ノード ──onion──▶ Tails / Android
[L] LLM   ──onion──▶ Tails / Android
[S] 署名（オフライン） ◀─QR/USB─▶ Tails（オンライン用、監視と送信のみ）
[B] N の複製（同期済み、通常は電源オフ）
```

- 最も安全。N と L が完全に分かれ、署名はネット未接続の専用機
- LLM は 1 台分（512GB）の範囲。十分大きい

### 案 B: 性能重視（N / L / L2 / S）

```
[N] ノード
[L]═══TB5═══[L2]  合計 1TB のメモリで分散推論
[S] 署名（オフライン）
```

- 1 台に載らない超大型モデル（1TB 級）が動く。ただし分散推論はソフトの成熟度が発展途上で、
  コピペ基準（ADR-007）との相性が悪い。予備機がなくなる

### 案 C: 段階導入（N / L / D / 未開封）

```
[N] ノード
[L] LLM
[D] 検証用（N や L の変更を先に試す。慣れたら S か B に転用）
[ ] 未開封のまま保管（用途が固まるまで、または再販）
```

- 学習コストを抑えつつ、選択肢を残す。「まずは 2 台で本番、1 台で練習」

### 案 D: 二重化（N / N' / L / S）

```
[N] ノード（本番）    [N'] ノード（別の場所に設置、常時稼働）
[L] LLM
[S] 署名（オフライン）
```

- ノードを 2 拠点で動かす。自宅の停電・回線障害・盗難でも検証能力が残る。
  別拠点（実家など）が必要

## 3. 推奨

**案 A（守り重視）を第一候補**とする。理由:

1. 利用者の目的は「生産性向上」であり、超大型モデルの研究ではない。512GB で足りる
2. 脅威モデルが 4 種すべてを対象にしており、署名の専用化（S）と予備（B）は直接それに効く
3. コピペ基準に収まる。分散推論のような発展途上の仕組みを本番に入れない

案 C は「まず 2 台で始める」入り口として案 A と両立する（D は後で S か B に転用）。
